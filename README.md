# AgentYou / 知微

An AI Agent that works as you.  Copy once and own an agent version of yourself.
一个主动帮你推进工作的 Agent， 复制一次你自己，他自动开始工作。 

# Installation / 安装

1 tell your agent to read this repo. 
2 enjoy

1 让你的 agent 读这个 repo
2 喝茶 and 与他聊天
