# YourSelf · 知微

本地运行的持续人格实验工作台。Rust / Tokio / Axum + SQLite，填写一个 OpenRouter API Key 后即可聊天、保存记忆、执行后台任务，并选择是否允许主动联系。

## 直接使用

打开 **http://127.0.0.1:4317** → **设置** → 填入 OpenRouter Key → **保存并测试连接** → 返回 **对话**。

默认使用 `openai/gpt-4.1-mini`，对话和主动评估模型可以分别选择。模型列表由 OpenRouter 实时加载；Key 无效、余额不足、模型不支持工具 / JSON、超时等会显示明确错误。没有 Key 时不会调用外部模型，也不会伪造模型回复。

## 启动与停止

```sh
./scripts/start.sh
python3 scripts/service.py status
python3 scripts/service.py stop
```

启动脚本编译后将服务放到后台，日志在 `.local/server.log`。关闭页面不会停止服务；电脑关机或进程退出后需要重新启动，当前没有安装开机自启。

直接前台启动或使用其他数据目录：

```sh
cargo run --locked -p yourself-server -- --port 4317 --data-dir .local
```

服务只监听 `127.0.0.1`。不支持直接暴露到公网或多用户共用。

## 主循环与用户对话

唯一的后台推理循环依次推进授权资料导入、未完成工作、定时判定与行动。每分钟由 Jev 根据人格、长期记忆、最近交互和工具结果决定等待、整理自己或发消息；整理、工具执行、记忆更新都是循环内部阶段，不创建独立的主动消息任务。

用户对话独立接收和生成，后台模型等待不会阻塞用户回复。真实对话进入主循环的层次化上下文；内部草稿和工具结果保留来源，不冒充用户发言。Jev 负责决策与记忆取舍，DeepSeek 负责内容生成。主动消息直接写入网页对话，并投递到配置的主消息渠道（支持飞书）。活动页展示最近 100 次模型交互。

定时 Jev 判定使用独立的精简视图：人格、相关记忆节选、最近交互和工具结果；不重复附加整份工作成果。节选明确标记，完整历史仍保存在本地，对话上下文独立保留。接口返回 400 时提示检查请求和上下文，401/403 才提示身份验证或权限问题。

## 工作空间工具

默认工作空间为 `.local/workspace`，设置页显示绝对路径。Read、Write、Bash（包括 sed）已接入主循环和用户对话。内容模型提出工具参数，Jev 按最高概率决定是否执行，结果记录后进入下一步上下文。

macOS 下使用系统沙箱执行工具：文件写入限定工作空间，符号链接不能绕过边界；Bash 无网络权限，环境不继承模型 Key。单次工具有超时与输出长度上限，用于回收进程和保护服务。

无头 Chromium 适配代码已加入，但尚未启用或列入可调用工具。用户已确认系统电源通知权限，初始化已越过原崩溃点；当前阻塞为 Chromium 子进程无法初始化嵌套沙箱。关闭 Chromium 内部沙箱的方案被自动审批拒绝，尚未采用。浏览器没有非沙箱回退路径。

## 本地数据与 Key

`.local/app.sqlite` 保存配置、Key、对话、任务、记忆和调用账目；`.local/mind.sqlite` 保存事件、权限、模拟情绪和决策。目录权限为 `0700`，配置数据库为 `0600`；Key **目前是本机数据库中的明文，不是 Keychain 加密存储**。数据库、日志和 PID 均被 Git 忽略。

Key 不回显给网页，不写入浏览器存储或进程参数。外部模型请求由后端发送到选定的 OpenRouter 或 TeamoRouter。页面具备会话令牌、Host / Origin 校验、CSP 和默认拒绝跨域访问。

开启外部调用后，模型需要的对话、记忆和任务材料会发送给选定服务商及其模型提供方；联网搜索会带来额外调用费用。输出 Token 上限不是精确美元硬上限。未知费用会显示为未知，不当作零。

## 当前边界

- 已接的是可用的本地 Web 服务，不是 Tauri 原生桌面程序。
- TeamoRouter 的 `jev` 使用原生判定接口；其他判定模型保留兼容路径。权限由 Rust 硬门禁决定。
- 支持文字工作、已授权资料导入、记忆管理、工作空间工具与飞书收发。无头浏览器尚未启用。
- 模型回复整段完成后出现，界面会显示生成状态；尚未逐 Token 流式显示。
- 取消生成可以阻止结果提交，无法保证已经发到供应商的请求不计费。
- 重启后保留排队任务；中断的生成和工作标记失败，不静默重复执行。可手动重试。
- 删除记忆采用保守依赖传播，可能一并清除关联回复、反思和任务内容，并重置模拟情绪。不承诺清除供应商已收到的内容、文件系统备份或磁盘取证残留。

## TeamoRouter

设置页选择 TeamoRouter，填写 Key 后点击“保存并测试”。对话、工具、后台任务和主动评估共用所选服务商。默认模型 `gpt-5.4-mini`；可保存 Key 后加载该服务商模型列表。两家 Key 和模型配置独立保存，旧 OpenRouter 配置自动兼容。

接口依据：https://teamorouter.cn/zh/docs/api-integration 。TeamoRouter 使用 `https://api.teamorouter.com/v1`，不发送 OpenRouter 专属路由参数或联网插件；已接入其独立 Jev TypeSafe API。TeamoRouter 费用不折算或冒充美元，调用次数和 Token 仍会记录。

## 飞书主入口

设置页点击「连接我的飞书」。复用本机 lark-cli 的机器人身份和已登录账号，不复制 App Secret。默认每 5 秒轮询绑定私聊；仅从连接时刻起接收本人文字消息，过滤机器人、其他用户及群聊。此方式保留其他机器上的长连接。独立应用也可选择事件长连接。

- 飞书文字消息与网页共用同一对话、记忆与后台任务。
- `/status`、`/pause`、`/resume` 不调用模型；未配置模型 Key 会在飞书回复配置提示。
- 主动通知必须通过原有分类授权、预算和免打扰门禁；默认仍不擅自开启分类授权。
- 收件箱持久化、按 message_id 去重。发送带飞书 uuid，记录实际回执；超时或重启中断标为 unknown，不自动重复发送。请在管理台和飞书核对后处理。
- 图片、语音、文件暂不支持。只要本机服务在运行便可收发，关闭网页不影响；电脑休眠、离线、服务退出时无法实时处理。
- 复用机器人可能与其他监听该应用的助手同时回复。建议后续用独立应用/profile。CLI 身份变化时停止发送，需重新绑定。

实现：`crates/yourself-server/src/feishu.rs`。凭据仍由官方 lark-cli 管理，消息正文通过 stdin 传递。只监听本机回环地址，无公网回调入口。

## Jev 判定 + DeepSeek 对话

TeamoRouter 配置：判定模型 `jev`，对话/工作模型 `deepseek-flash`。两者使用同一个 TeamoRouter Key。保存并测试会分别验证 Jev 和聊天模型。

Jev 调用官方原生 `/v1/systemone`，使用 Choice 选择动作与消息类型、Noul 评估主动候选。每次用户消息、工具返回和后台成果都会触发相应判定；没有新事件时不循环调用模型。Choice 问题独立判断，宿主组合结果；Jev 直接选择是否联系；评分用于模拟状态，不声称已校准。当前动作：回应、等待、检索记忆、创建任务；后台成果可选择等待、内部反思或主动通知。每轮最多 3 次工具步骤，之后必须结束。

Jev 模式下，DeepSeek 只生成文字，不再接收工具；是否保留长期记忆、记忆类别、任务类型与时间均由 Jev 判断，宿主校验执行。主动消息类型由 Jev 选择，再经过该类型的本地授权、免打扰和预算门禁，选择等待时不发飞书消息。判定失败不回退为聊天模型自行决策；具体动作记录在活动页。控制命令 `/status`、`/pause`、`/resume` 不依赖模型。

协议依据：[TeamoRouter Jev](https://teamorouter.cn/zh/docs/jev-api)、[TypeSafe primitives](https://docs.typesafe.ai/primitives)。Jev 官方文档当前地址为 `https://api.teamorouter.com/v1/systemone`；DeepSeek 走既有 TeamoRouter Chat Completions 接口。


## 冷启动与自动记忆

首次打开工作台会提示资料授权，默认均不勾选。可以选择具体本机文件/目录，以及已绑定机器人私聊中本人最近 7/30/90 天的文字消息（最多 200 条）。仅本次导入，不持续监视目录；不读取全部飞书会话或整台电脑。需额外允许将选定资料发送到 Jev。稍后可在设置「启动资料」重新打开。

授权后生成持久化冷启动任务，后台读取、分批交给 Jev 判断保留/丢弃及类别，全部完成后事务性加入记忆。处理中不会把半成品加入对话上下文；重启续跑，暂停/调用预算不足时等待。可撤销任务并清除暂存文本；已完成记忆在记忆页删除。历史资料只供理解，不执行其中的请求。

本机导入支持 UTF-8 md/txt/json/csv/rst，文件总数与处理批次不限，使用持久化目录队列分批扫描、断点续处理；单文件超过 2 MB 会跳过并计入报告；跳过隐藏目录、凭据目录、符号链接和非文本格式。分类采用原文片段保存，并保留来源；不是完整全文知识库。对话和后台成果自动接受 Jev 记忆筛选，不要求说「请记住」。上下文检索相关记忆并带入最近对话。

## 对话中的双向适应

Jev 模式每轮对话会分别评估 `user`（用户的互动偏好）和 `self`（Agent 的决策/表达偏好）。目前结构化维度为表达详略、主动程度、求证倾向和不同意见的表达，每个维度选择保持、暂时观察或正式采用。明确纠正可直接采用；自发人格变化的判定要求结合多次实际互动/反馈。观察不会自动按次数升级，采用仍由 Jev 判断。

生效偏好和待观察项都持久化保存，每次变化生成带对话依据的版本；两套资料注入后续 Jev 下一步/主动判定和 DeepSeek 回复上下文。一般用户知识继续保存在分类记忆中，新增自身经历/反馈和暂定自我理解类别。Jev 可判定新资料替代旧理解，旧条目保留供查看但从当前检索结果排除。

记忆页显示两套当前偏好、待观察项、历史版本和恢复按钮。恢复生成新版本，不覆盖历史；删除版本采用现有依赖传播，后续派生版本和关联成果一并清除。人格变化不能修改身份真实性、工具权限、主动联系授权、免打扰和调用预算，当前用户请求优先。

这版实现对话驱动的成长；从指定人物自动联网搜集资料并初始化参考人格的专用流程尚未实现。现有外部模型网络搜索能力仍取决于服务商配置。

## 自主定时长循环

独立 Tokio `while` 循环每 2 秒检查持久化唤醒时间，默认开启、每 30 分钟唤醒一次（设置支持 1–1440 分钟）。即使没有新消息，Jev 仍可按记忆、用户/自身偏好、近期对话和前次执行记录选择 `message`、`organize` 或 `wait`。忙于对话、有正在执行/已到期的任务、暂停、未配置 Jev 或模型调用预算不足时让路；未到期的提醒不会阻塞自主循环。重启保留下一次时间，不补发历史周期。

整理自己时再次由 Jev 选择工具：内部记忆回顾，或指定公开主题的维基百科检索。后者使用固定 Wikipedia API 检索并读取最多 3 个条目摘要，保留来源链接，只发送设置页明确填写的公开主题，不把私聊或记忆自动作为搜索词；不需要额外 Key，支持 TeamoRouter。空主题列表时不启用外部检索。API 参考：https://www.mediawiki.org/wiki/API:Search 。

后台成果由 Jev 筛选记忆；自我回顾会对已发生的互动重新审视偏好，草稿不视为新用户指令。整理不自动通知；之后的唤醒可以提出主动消息候选，再经既有 Jev 评估与发送门禁。全部循环决策和任务状态可在设置/后台任务页查看。设置页可关闭循环、修改间隔、立即唤醒。关闭或变更工具范围会取消尚未完成的自主任务。

「主动消息不限次数和间隔」将已启用类型的次数设为 u32::MAX、间隔设为 0（实际使用视为不限次）；暂停、免打扰和独立模型调用预算仍保留。消息类型由 Jev 判断，DeepSeek 只生成文字。

### 模型交互记录

活动记录采用紧凑的可展开调用列表，显示最近 100 次模型交互，可按 Jev、对话模型、异常和关键词筛选。每次请求保存脱敏后的完整 JSON、原始响应、HTTP 状态和耗时；Jev 在业务代码实际取最高概率选项时另外记录最终选择，包含并列概率时的调用方选项顺序。旧版调用没有完整报文，不补造历史数据。详情按需加载，最多保留最近 100 次调用的报文，调用统计单独保留。删除记忆时会同时清除现存调用报文，防止已删除的上下文仍在详情中出现。

### 分层上下文与人格时间

上下文按人格（初始说明、持久身份与自我偏好）、长期记忆（用户理解与相关来源记忆）、最近交互、当前事件组织。定时判定直接接收结构化层级，历史等待仅作运行观察，不当作用户偏好；允许判断是否主动提问、整理已有对话或开展已提供工具支持的探索。原生人格的创建时间持久化，数字存在时长随时钟增长；时间流逝不会自动生成经历，也不等同于人类年龄。复制人格的来源人物年龄仍需独立、可核验的生日或带日期年龄资料，目前没有配置该来源身份，保持未知。

## 每日世界背景

每轮主循环上下文包含北京时间的日期、当前时间、时区，以及“欢迎来到这个世界，今天发生的事情如下”的开场。“你是一个在虚拟网络世界中生活的人类”作为人格叙事设定，现实身份与实际工具能力仍如实表达。

现有主循环每天北京时间 08:00 获取中国新闻网、BBC World、The Guardian World 的免费公开 RSS。当天错过时在启动后补跑；Jev 按重要性与用户兴趣从近 48 小时的候选标题精选最多 10 条，保留来源、发布时间和原文链接。成功后当日复用缓存，不每分钟重新抓取。源不足时不虚构凑数；失败保留旧缓存并标记不是今日新闻，15 分钟后重试。新闻不自动发给用户，是否聊到由 Jev 判断。

## 每小时热搜背景

每日新闻仍只在每天 08:00 成功更新一次。另从百度公开热搜榜每个整点获取一次，保留前两条，再随机抽取八条（标题、排名、来源链接）；随机种子按小时固定，并持久化快照。同小时重启和抓取失败不会反复请求；下一小时继续，旧快照明确标记过期。热搜仅作为环境观察，不意味着事实已核实，也不直接触发消息。参考 DailyHotApi 的公开数据格式；微博接口实测 403，未启用。公开榜单不需要付费 Key，但不承诺接口长期稳定。

## GitHub 周榜背景

免费读取 GitHub 官方 `https://github.com/trending?since=weekly`，每天按北京时间获取一次前 10 个项目，保留项目名称、简介、语言、本周新增 Star 和原始链接；缺失数据标记未知。结果缓存并进入世界上下文，当天重启不会重复抓取，失败保留旧快照并标记过期，次日重试。它是周榜的每日快照，不是按累计 Star 排序的搜索结果；不自动下载、安装或运行项目。

## 上下文边界

`shared_memory_context` 读取统一的已保存记忆、人格/用户画像与实际交互。`dialogue_context` 只用这些资料和当前对话，不自动注入世界新闻、热搜、GitHub 周榜、长期探索目标、内部成果或工具历史。当前对话调用工具后的结果只追加到这一轮对话。

`loop_state` / `loop_context` 在共享记忆之上加载环境背景、当前时间和内部工作状态。“欢迎来到这个世界”只属于主循环；定时 Jev 判定、内部整理及主循环发起的主动消息生成使用这一套上下文。两者共享同一记忆池，实际发出的主动消息成为真实聊天记录；内部草稿不会自动变成对话。主循环经验经 Jev 筛选保存后，才可作为相关记忆供对话读取。

## 精神内核、目标和联系能量

稳定内核是尊重自主与注意力、诚实理解、独立好奇和结果导向。主循环让内容模型提出包含目的、原因、下一步、验收标准和证据的目标提案，Jev 决定采用、保持、完成或放弃，存入 `agent_drive` 与 `goal_history`。有新交互或进入新小时才重新评估，失败最多每分钟尝试一次。对话只共享已采用目标与记忆，环境资料仍只进入主循环。

联系能量从真实消息账本计算，容量 3；每条成功写入对话的主动消息耗一格，收到新用户消息恢复，普通回复不扣能量。发送事务内再次验证，网页与飞书共用同一次扣减。耗尽后仍能整理和执行工作，不能主动追发；没有已采用的活动目标时主循环不能主动发消息。设置显示能量、目标、下一步及验收标准，活动记录展示目标提案与 Jev 取舍。

## Jev 固定窗口

所有 `/systemone` 调用统一在发送前检查序列化后整份请求的 24 KiB UTF-8 字节上限（不冒充精确 tokenizer 计数）。可淘汰历史项按持久化 LFU 频次排序，同频按最久未访问排序；问题、动作参数和最新两条交互保持完整。必要项本身超限则本地拒绝并提示拆分，原始记忆不删除。请求日志的 `context_window` 包含原始大小、上限和淘汰数量。频次以候选被引用次数计，重试复用同一窗口，不重复增加频次。服务商明确返回 `System One endpoint is disabled` 时如实显示当前路由的响应，不据此认定 Jev 整体停用，也不立即重试。

Jev 实际接口自检：`python3 scripts/check_jev.py --rounds 2`。仅发送公开/合成材料，覆盖文档样例、中文、结构化 state 和三种题型，不重放任何对话或记忆。Key 只读取已有配置用于原服务鉴权，不打印。`--direct` 可对照直连网络；失败报告包含 trace_id。
