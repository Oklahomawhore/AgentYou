# 注意力与 Skills

本次修订保持产品服务停止，仅用本地 mock 和离线测试验证。此前 endpoint 单独复测 4/4 返回 HTTP 200；这不等同于新行为已通过线上长期验证。浏览器仍未启用。

## 三层自然语言与系统参数

心智方向只存三段自然语言：长期在乎什么、近期持续关心什么、此刻关注什么。原因、经历、进展、困惑和对话意图融入叙述，不要求 objective、evidence、next_step、success_criteria 等字段，没有完成、放弃、休眠状态机。JSON 仅用来传输三段文字和系统参数。

| 层次 | 粘性默认值 | 每小时关注强度衰减 | 改写原则 |
| --- | --- | --- | --- |
| 长期 | 0.95 | 0.05 | 除非重大经历或持续根本矛盾，保留连续性 |
| 中期 | 0.70 | 0.50 | 根据累积的相关反馈逐渐调整 |
| 短期 | 0.20 | 5.00 | 可以被新信息、当前对话打断或改变 |

关注强度初始为 60，范围 0–100。Jev 分别判断每层是否保留或采用候选文字，并独立判断关注强度保持、增强或减弱。增强／减弱的幅度为 `12 × (1 − 粘性)`；衰减按真实经过时间计算，包括离线时间。这些系数是初始运行参数，不是心理测量或概率。

**零分不删除或废弃任何叙述，也不会自动寻找替代目标。** 是否转换关注、如何理解重大变化，由 Jev 阅读实际经历和参数后判断。改写文字不重置分数，不再通过比较目标名称制造新目标。长期抗干扰由高粘性参数和 Jev 的分层判断共同表达，不是程序枚举“重大变故”。

主循环读取三层叙述、人格、记忆和真实反馈，DeepSeek 提出三段完整候选文字，Jev 逐层决定采用与否。无新理解时保留原文，允许空白，不为填字段编造目标。消息、工具、世界信息变化或跨小时触发复查；系统版本指纹避免同一批观察重复增强分数，内容相关性仍由 Jev 判断。

用户对话共享三段叙述，但不带主循环数值参数、新闻和内部工作。模型结合当下用户表达形成自然的对话意图，可以理解、陪伴、探索或做事，不要求每次拿到结论。实际对话再回流主循环。主循环额外按三层叙述检索关注相关记忆，并纳入统一 LFU 请求窗口。

旧版目标的原因、下一步、进展和历史状态会转成中期自然语言历史；长期和短期先留空，等待实际理解。数据库兼容保留旧表名，表名不代表仍存在目标生命周期。设置页显示三段文字与分层参数。

## Skills 是可复用方法

新增三个工具：

| 工具 | 行为 |
| --- | --- |
| SkillList | 返回最近的 Skills 摘要与版本，最多 50 项 |
| SkillRead | 按名称读取最新完整方法，包含来源 ID |
| SkillSave | 保存新方法或修订版本；相同内容和来源不重复创建版本 |

Skills 保存在本地 SQLite 的 `learned_skills` 表。内容为 Markdown 方法说明，包含适用条件、步骤、验证和失败边界；它们不成为更高优先级系统指令，也不扩大 Bash、文件或网络权限。

主循环整理阶段可以选择 `learn_skill`，依据真实经验提出 SkillSave。DeepSeek 提出完整参数，宿主验证来源存在，Jev 查看具体方法与来源后决定 execute / skip，通过后才保存。来源可以是实际用户指导，或成功的 Read / Write / Bash / Browser 结果；不接受失败工具结果、内部草稿或 SkillSave 自身充当成功证据。

工具成功只证明该次工具执行成功，不代表方法已普遍验证；是否从来源归纳出合理方法仍由 Jev 审定。每次实际应用继续走工具授权、执行和结果记录。可通过 SkillRead 获取方法，再在后续循环或对话工具步骤应用。来源删除时，现有保守删除流程同时清理 Skills，防止保留派生私人内容。

外部 Skill 可以放入授权工作空间，通过 Read 读取 `SKILL.md`，由模型整理成 SkillSave 提案并经 Jev 审定；不自动扫描全机 Skills，也不直接执行导入包中的脚本。需要导出时，可 SkillRead 后通过 Write 写入工作空间的 `skills/<name>/SKILL.md`。第一版是方法学习与复用，不是通用插件包管理器。

新增测试覆盖分层衰减、重复增强去重、零分保留叙述、改写不重置分数、分层独立审定、旧数据兼容和主循环与对话隔离、世界快照内容去重、Skill 来源校验、版本持久化，以及 Jev 拒绝时不写入、允许后才保存。原有模型、飞书、记忆、工具权限测试继续回归。

## 判定上下文链路修复

程序先对 Jev 输入做 LFU 历史淘汰和有界观察摘要；超长系统消息也不再被当作不可裁剪资料。问题按四个一批发送，记忆修订不在题干重复复制记忆全文，片段索引保持稳定。每批答案保留其实际调用的审计关联。

对话系统指令与共享资料拆开。生成回复前 Jev 根据最新用户消息和分批资料预览选择 include / omit，宿主将选中的原文交给对话模型；基础指令和最新用户消息保留。活动页新增“Jev 对话上下文筛选”。摘要带有省略标识，不删除数据库原文。

工具具体参数不按观察摘要裁剪；超过当前单次审定预算的工具提案返回未执行和拆分提示，由后续工具轮次重新提出较小操作。浏览器原有未启用状态不变。

## 上下文时间

普通对话历史原先在转换为 role/content 时丢失了数据库时间，现已将发送时间写入模型可见的消息正文。每次 DeepSeek 调用同时携带当前请求时间、Asia/Shanghai 时区；历史消息标记发送时间与距上下文组装时的秒数。Jev 的候选预览保留这些标记，判定输入另有当前时间。

共享资料带更新时间（可查时）或明确标记未知；记忆、人格版本等对象保留创建／更新时间并补充可读标签。主循环工作记录、工具结果和 Skills 目录也带记录时间。记录时间不能作为内容所描述事件的发生时间；无新记录不能推断期间没有活动或文件未变。

目前配置的对话请求为 TeamoRouter `/v1/chat/completions`、`model=deepseek-flash`、`max_tokens=2048`、`temperature=0.7`、`stream=false`。这是当前本机配置而非固定默认值。对话消息依次为宿主说明与当前时间、Jev 选中的共享资料、带时间的实际交互、宿主执行结果说明。最终回复调用不附带工具定义；工具提案调用另行提供工具，结构化内容调用可使用 `response_format` 并将 temperature 设置为 0.2。
