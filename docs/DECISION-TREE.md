# 主循环分层决策

每分钟只触发一次主循环；用户对话仍是独立上下文，共享人格、记忆和三段自然语言关注。

1. 有新的用户反馈、实际工具结果或世界信息时，Jev 同批判断四个分支倾向应增加、减小还是保持。无新材料跳过；自己的发言、内部草稿和经过时间不计作新反馈。相同材料按持久化版本去重，重启不重复强化。倾向初值 50，每次调整 8，范围 5–95；这是程序参数，不是模型概率。沿用已有注意力模块的三层粘性。
2. Jev 选本轮方向：message、continue_interest、explore、no_action。没有已有方向时移除 continue_interest；联系历史不设发送上限。方向和用意按合法正概率抽样（系统随机源混合上海环境，记录种子）；工具授权等仍取最高概率，不把倾向分数与模型概率相乘。
3. 程序从当前三层自然语言、最近真实用户表达、已有工作和授权公开主题构造本轮用意候选，Jev 再选具体用意，可以在此放弃。候选是实际材料的自然语言摘录，并非固定的消息目的枚举；当前版本不是让模型自由编造新的目的文本。
4. 同批判断记忆、工作材料、世界信息是否需要传入下一层。主动联系由 DeepSeek 按已选用意生成正文；工作分支再由 Jev 选工具，并通过现有工具授权和执行链路推进。内部工作不自动生成用户消息，也不新增定时任务。

树节点的 state 是按节点筛选的 Markdown 字符串，问题在 questions 中。保留时间、人格、三层关注、最新对话及所需材料的节选；不发送 LFU 统计、旧配额开关或历史接口错误。上下文预算是按区块分配的，本机完整记录不会被删除。

反馈更新失败时使用已保存倾向继续本轮方向判断；失败仍在模型活动中可见。新对话或设置变化使过时的分支失效。具体用意持久化到 decision_paths，仅供回看；不是新的目标或任务生命周期。删除来源记忆时同时清除路径记录、重置倾向，避免残留派生理解。

活动记录显示反馈、方向、用意、工具各层的模型选项、概率和最终选择；循环面板显示当前倾向和每轮用意。暂不行动只跑方向层；主动联系通常为方向、用意、正文三次调用，有新反馈时增加一次包含四个问题的判定。采用本地模拟接口验证分支与上下文边界，不将历史私人请求用于额外 A/B 重放。
