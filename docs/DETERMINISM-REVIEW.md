## 仍然影响行为的确定性约束

| 约束 | 当前状态与影响 |
|---|---|
| 每分钟唤醒、单轮互斥 | 保留，调度频率不是发送配额；对话忙时等待，用户新消息使旧主动草稿失效 |
| 四方向与第二层 no_action | 保留；候选不是无限开放，第二层仍可以撤回行动 |
| 用意候选 | 由自然语言关注、最近交互、成果、世界信息和公开主题拼出，最多六个；不是任意生成的决策树，候选不足时可能偏静默 |
| 没有已有方向 | 移除延续兴趣选项，避免虚构延续对象；不移除联系或探索 |
| 历史倾向参数 | 初始 50，新证据由 Jev 判断 ±8，范围 5–95；仅作为提示词观察，不与概率相乘；相同证据不会重复强化 |
| 注意力 | 长/中/短粘性 .95/.7/.2，初始强度 60，小时衰减 .05/.5/5；自然语言关注不自动删除 |
| 上下文节选 | 常规字段 650 字，环境 1800 字，最近四条交互每条 90 字，关注每层 160 字；可能丢失语气与动机。下游并非所有历史原文 |
| Jev 请求窗口 | 24576 字节、问题分批、可选资料淘汰/投影仍保留；这是传输限制，会影响所见信息 |
| 对话/工具轮数 | 对话最多四轮、工具最多四调用和三工具轮；限制单轮资源消耗 |
| 外界来源频率 | 新闻每天、热搜每小时、GitHub 周榜按日更新；环境每小时，读取失败不等于没有外界变化 |
| 精神内核和表达提示 | 仍要求诚实、不重复追问、不编造用户动机；这些语义约束仍可能降低主动概率，但不形成代码发送配额 |
| 旧配额/免打扰 | 兼容路径仍有旧政策代码；当前 AI 自主模式清除每日上限、冷却和静默限制，不用于当前行为控制 |
| 工具与渠道保障 | 工作空间写边界、云调用权限、凭据检查、发送幂等、未知发送不自动重发保留；渠道的旧主动消息过期过滤仍可能阻止积压消息补发（约五分钟） |

删除条数上限不等于保证多发：需要观察新版的分布、抽样选择及用意层撤回率，才能继续判断是否是候选质量或上下文压缩的问题。
